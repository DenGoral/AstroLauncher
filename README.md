# AstroLauncher

**A modern, open-source Minecraft launcher built with C# and Avalonia UI.**

AstroLauncher aims to provide a clean, intuitive and customizable experience for managing and launching Minecraft, with a focus on modern design, usability and extensibility.

> **Status: Early Development**
>
> AstroLauncher is actively being developed. Its redesigned interface is still a work in progress, and some planned features have not yet been implemented.

## Features

### Implemented
- **Modern UI** — A redesigned interface with dedicated Home, Instances, Discover and Settings pages.
- **Minecraft Version Retrieval** — Retrieve available Minecraft versions from Mojang (legacy implementation).
- **Minecraft Launching** — Launch Minecraft using the legacy implementation.
- **User Settings** — Basic launcher settings and username persistence in the legacy version.

### In Development
- Integration of Minecraft launching into the redesigned interface.
- Improvements to UI consistency and usability.
- Bug fixes and application stability improvements.

### Planned
- **Mod Support** — Browse and manage mods from Modrinth and CurseForge.
- **Instance Management** — Create and manage separate Minecraft installations.
- **Modpack Management** — Simplify modpack creation and management.
- Further customization options.

## Technologies

AstroLauncher is built using:

- **C#** — Main programming language.
- **.NET** - Application runtime and development platform.
- **Avalonia UI** - Cross-platform UI framework.
- **XAML** — Declarative markup for designing the application interface.
- **Git & GitHub** - Version control and source code hosting.

## Project Structure

Development is currently split across different Git branches:

- `legacy-ui` — Previous launcher implementation with working Minecraft launching and version retrieval.
- Current development branch — Redesigned interface and ongoing application
